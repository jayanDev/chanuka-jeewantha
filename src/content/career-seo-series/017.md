# ATS CV Formatting: The Simple Rules Most Job Seekers Ignore

Good ATS CV formatting keeps career information connected and readable. Consistency matters more than decorative complexity or a supposedly perfect template.

Use the following rules to build a document you can maintain. They are practical defaults, and an employer's explicit instructions should take priority.

## Create a clear information hierarchy

Place your name and contact details first, followed by a relevant profile and the strongest evidence for your career stage. Use familiar section headings. Keep employer, title, location where useful and dates together in each experience entry.

Do not rely on position alone to explain relationships. A date floating in a distant sidebar may look aligned on one screen but become confusing when text is extracted or the page layout shifts.

## Make styles consistent

Choose one body font and a small number of heading styles. Use the same date pattern across roles and education. Keep bullet spacing and indentation consistent so the reader can concentrate on the content.

Treat bold text as a guide, not a decoration for every second phrase. If everything is emphasised, nothing stands out. Avoid shrinking the body text simply to preserve an arbitrary page count.

## Keep meaningful information as text

Write email addresses, phone numbers, tools and qualifications plainly. Do not communicate skill levels solely with graphics. Avoid placing the only copy of essential information in a shape or image.

A useful skills entry explains capability: “Excel: pivot tables and monthly reconciliation workbooks.” It is clearer than a percentage that has no defined measurement behind it.

## Control page breaks deliberately

Check that a role heading is not separated from all its bullets. Look for a second page containing only a few lines or an education entry split awkwardly across pages. Use paragraph and page-break controls instead of repeatedly pressing Enter to force alignment.

Reopen the exported file after changes. Editing software and viewers can show layout differently, so the final download deserves its own review.

## Verify the submitted version

- Open every page and check spacing, symbols and links.
- Copy the text into a plain document and inspect its order.
- Confirm the file type and size meet the portal's stated requirements.
- Review auto-filled application fields before submitting.
- Keep the exact version you sent.

These checks reduce avoidable presentation problems. They do not guarantee a hiring outcome or compensate for missing evidence. For a structured starting point, explore the [free CV resources](/resources); for a document-specific assessment, use [CV review support](/services/packages/cv-review).

## Frequently Asked Questions

### Is one font mandatory?

No. Consistency and legibility are the goals. Using one font is simply an easy way to avoid unnecessary visual variation.

### Are all tables forbidden?

No universal rule covers every document and system. If a table makes reading order or editing unreliable, replace it with ordinary paragraphs.
