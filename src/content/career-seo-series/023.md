# PDF or Word: Which CV Format Is Better for ATS?

Use the file type the employer requests. When both PDF and Word are accepted, choose a clean, text-based document and inspect the final version before uploading.

Neither extension guarantees a readable CV. A scanned PDF can behave very differently from a text-based PDF, while a Word document can contain complicated objects and unstable page layouts.

## Follow the application instructions first

Check the vacancy, upload field and any recruiter message for accepted formats and size limits. Do not send your preferred type if the employer explicitly asks for another. If instructions conflict, seek clarification where practical rather than guessing.

Keep an editable master so you can produce another version without rebuilding the CV. Save the final application file separately from your working draft.

## Review a PDF as a finished document

A PDF is useful for presenting a fixed layout. Open every page after export and check that text is selectable, links work and nothing has been clipped. Copy a section into a plain document to inspect the reading order.

Do not assume that a PDF made from photographs or screenshots contains useful text. If all you have is an image, rebuild the CV in an editable document before exporting a proper application version.

## Review a Word file for editing artefacts

Check for comments, tracked changes, highlighted instructions and accidental blank pages. Make sure another reader will not see unresolved edits or an earlier version of a sentence.

Use consistent styles and sensible page breaks. A document that depends on many spaces, floating text boxes or unusual fonts may shift when opened elsewhere. Preview it in another available viewer if you can.

## Verify what the portal received

After upload, inspect any document preview and automatically populated fields. Correct extraction mistakes where allowed. Confirm that the file attached is the right version for the employer and role.

Use a filename that identifies you and the document without clutter, such as your name and target role. Avoid filenames that expose internal notes or suggest the file is an unfinished draft.

## Make a reusable submission routine

Keep the editable master, an exported version and a record of which file you submitted. Repeat the check after substantial edits, because a new bullet can create an awkward page break.

If you request [CV writing support](/services/packages/cv-writing), confirm the supplied formats in advance. A [CV review](/services/packages/cv-review) should examine the final export as well as the wording when file usability is your concern.

## Frequently Asked Questions

### Should I always send PDF?

No. Follow the employer's instructions. If a recruiter specifically requests Word, provide a clean Word version.

### Does changing the extension convert a file?

No. Export or save the document using the appropriate format in your editor. Renaming an extension does not change the underlying file.
